# CJ-Helmet

Индикация шлема по данным моноколеса Sherman L: габарит, торможение, разгон, поворот.
ТЗ: /srv/claude/knowledge/docs/tz-sherman-shlem.md.

Схема: колесо -> телефон (форк WheelLog, модуль «Шлем») -> BLE -> ESP32 в шлеме.
Поворотники: кнопки на руле или руке -> ESP-NOW -> шлем.

## Где что

- Исходник: git на NL `/root/helmet`, копия для сборки на MiniGUN `/opt/helmet`.
- `fw/` - прошивка (PlatformIO, Arduino-ядро 3.x через pioarduino, NimBLE-Arduino, Adafruit NeoPixel).
- `tools/test_ble.py` - проверка шлема по BLE с MiniGUN (bleak).
- На MiniGUN всё своё в `/opt/helmet`: venv с PlatformIO 6.2 и bleak (`venv/`),
  кэш платформы (`.platformio/`), сборка `sobrat.sh`. ESPHome не задевается.

Сборка и прошивка на MiniGUN (плата на USB, родной порт C6 -> /dev/ttyACM0):

    /opt/helmet/sobrat.sh                          # сборка
    /opt/helmet/sobrat.sh -t upload                # прошить
    /opt/helmet/venv/bin/python /opt/helmet/tools/test_ble.py

## Плата

MuseLab nanoESP32-C6, флеш 16 МБ. Лента - `PIN_LENTA` в `fw/src/main.cpp` (GPIO18),
светодиод на плате - GPIO8. Пока ленты нет, режим видно по светодиоду на плате:
габарит - тускло красный, стоп - ярко красный, разгон - цвет разгона,
поворот - жёлтое мигание, нет связи - красный мигает раз в секунду, разметка - белый.

## BLE

Имя `CJ-Helmet`, сервис `e5c7e8c9-d675-4a18-81ca-fe8e20469649`. Всё little-endian.

| Характеристика | UUID | Доступ |
|---|---|---|
| data | `e7af526e-d864-4f2c-a552-34f2f8265c65` | write without response |
| config | `0754273b-03f6-4547-ac98-f6652dd7cb00` | read, write (33 байта, длинная запись) |
| state | `ca1c4800-cea8-44c2-8e14-3be95eb3af36` | read, notify |

**data**, пакет v1, 8 байт: `[ver=1][flags][speed s16 0.1 км/ч][current s16 0.1 А][pitch s16 0.01 град]`,
`flags` бит 0 - колесо на связи. Слать при каждом обновлении WheelLog, не чаще 20 раз в секунду.
Другая длина или версия - пакет отброшен (счётчик `bad`).

**config**, 33 байта (структура `Config` в `fw/src/protokol.h`), пишется целиком, хранится в NVS:

| Смещение | Поле | По умолчанию |
|---|---|---|
| 0 | ver u8 = 2 | 2 |
| 1 | яркость габарита u8 | 40 |
| 2 | яркость стопа и поворота u8 | 255 |
| 3 | флаги: 0x01 ток с обратным знаком, 0x02 белый спереди, 0x04 режим разметки | 0 |
| 4 | сглаживание ускорения u16, мс | 250 |
| 6 | порог торможения по замедлению u16, 0.1 км/ч в секунду (0 - выкл) | 50 |
| 8 | порог торможения по току рекуперации u16, 0.1 А (0 - выкл) | 0 |
| 10 | порог разгона u16, 0.1 км/ч в секунду (0 - выкл) | 40 |
| 12 | мин. скорость для разгона и тока u16, 0.1 км/ч | 30 |
| 14 | точек в ленте u16 | 135 |
| 16-22 | границы зон u16 x4: правый бок, дуга сзади, левый бок, перед слева | 15, 55, 80, 120 |
| 24 | цвет разгона RGB | 0, 200, 160 |
| 27 | поворот гаснет через u8, с | 15 |
| 28 | предел тока ленты u16, мА | 2000 |
| 30 | порог торможения по наклону назад сверх среднего u16, 0.01 градуса (0 - выкл) | 250 |
| 32 | среднее наклона за u8, с | 8 |

Неверный config (версия, границы не по порядку, вне пределов) не применяется.

Зоны: точка 0 - справа спереди у подбородка (вход ленты). `[0, z1)` перед справа,
`[z1, z2)` правый бок, `[z2, z3)` дуга сзади, `[z3, z4)` левый бок, `[z4, N)` перед слева.
Режим разметки: каждая 10-я точка белая, каждая 50-я синяя, точка 0 зелёная, границы зон малиновые.

**state**, 12 байт: `[mode u8][turn u8][accel s16 0.1 км/ч/с][speed s16][packets u16][bad u16][ma u16]`,
mode: 0 нет связи, 1 норма, 2 торможение, 3 разгон; turn: 0 нет, 1 лево, 2 право, 3 оба.
Уведомление при смене режима или поворота и раз в секунду.

## Логика

- Ускорение - производная модуля скорости, сглаживание экспонентой с постоянной `smooth_ms`.
  Медианы нет: Sherman L шлёт 5 пакетов в секунду, в логах 20 и 22.10 ни одного одиночного выброса скорости.
- Торможение по наклону: наклон назад минус его среднее за `tilt_avg_s` (уклон дороги уходит в среднее),
  от 5 км/ч. По логам наклон опережает замедление на ~0.4 с.
- Торможение: замедление выше порога, наклон выше порога или ток рекуперации выше порога (ток против направления
  движения; WheelLog по умолчанию отдаёт ток по модулю, поэтому выключено; флаг 0x01 инвертирует). Выход на 60% порога,
  стоп и разгон держатся не меньше 300 мс.
- Нет пакетов дольше 1 с, BLE отключён или flags бит 0 = 0 - «нет связи»: ровный габарит, стоп не держится.
- Поворот поверх боков, дуга сзади остаётся стопом или габаритом. Спереди красного нет.
- Предел тока: расчёт 20 мА на канал на полной яркости + 1 мА на точку, выше предела всё притушивается.

## ESP-NOW (кнопки поворотника)

Канал 1, пакет 4 байта: `'C' 'J' 1 cmd`, cmd: 0 выкл, 1 лево, 2 право, 3 аварийка.
Повторная команда того же поворота гасит его. MAC шлема печатается в USB-лог при старте.

## Отладка по USB

115200, команды: `l` `r` `b` `o` - поворот лево, право, оба, выкл; `c` - режим разметки вкл/выкл;
`d` - настройки по умолчанию; `s` - состояние.
