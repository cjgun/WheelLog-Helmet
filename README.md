# CJ-Helmet

Индикация шлема по данным моноколеса Sherman L: габарит, торможение, разгон, поворот.
ТЗ: /srv/claude/knowledge/docs/tz-sherman-shlem.md.

Схема: колесо -> телефон (форк WheelLog, модуль «Шлем») -> BLE -> ESP32 в шлеме.
Поворотники: кнопки на руле или руке -> ESP-NOW -> шлем.

## Где что

- Исходник: git на NL `/root/helmet`, копия для сборки на MiniGUN `/opt/helmet`.
- `fw/` - прошивка (PlatformIO, Arduino-ядро 3.x через pioarduino, NimBLE-Arduino, Adafruit NeoPixel).
- `tools/test_ble.py` - проверка шлема по BLE с MiniGUN (bleak).
- На MiniGUN всё своё в `/opt/helmet`: venv с PlatformIO 6.2 и bleak (`venv/`),
  кэш платформы (`.platformio/`), сборка `sobrat.sh`. ESPHome не задевается.

Сборка и прошивка на MiniGUN (плата на USB, родной порт C6 -> /dev/ttyACM0):

    /opt/helmet/sobrat.sh                          # сборка
    /opt/helmet/sobrat.sh -t upload                # прошить
    /opt/helmet/venv/bin/python /opt/helmet/tools/test_ble.py

| Плата | Где | Лента | Прочее | Сборка |
|---|---|---|---|---|
| MuseLab nanoESP32-C6, 16 МБ | шлем HJC | GPIO18 | RGB-светодиод GPIO8 | `-e nano-c6` |

Выводы - в начале `fw/src/main.cpp`. Имя в эфире по `kind` в config: `CJ-Helmet` или `CJ-Wheel`.

## BLE

Сервис `e5c7e8c9-d675-4a18-81ca-fe8e20469649`. Всё little-endian. MTU 247 (кадры по 183 байта).

| Характеристика | UUID | Доступ |
|---|---|---|
| data | `e7af526e-d864-4f2c-a552-34f2f8265c65` | write without response |
| config | `0754273b-03f6-4547-ac98-f6652dd7cb00` | read, write (74 байта, длинная запись) |
| state | `ca1c4800-cea8-44c2-8e14-3be95eb3af36` | read, notify |
| cmd | `4f1d2a6e-8c3b-4e57-9a10-6b2d7c9e0f31` | write |
| frame | `9b7e3c21-5d4a-4f68-b2e1-0c8a6f4d2e95` | notify |

**data**: v1, 8 байт `[1][flags][speed s16 0.1 км/ч][current s16 0.1 А][pitch s16 0.01 град]` или
v2, 11 байт - то же + `[pwm u8 %][battery u8 %][alarms u8, бит 0 - тревога колеса]`. `flags` бит 0 - колесо на связи.
Слать при каждом обновлении WheelLog, не чаще 20 раз в секунду. Другая длина или версия - пакет отброшен (`bad`).

**config v4**, 74 байта (`Config` в `fw/src/protokol.h`), пишется целиком, хранится в NVS. Старые версии (30, 33, 34 байта)
переносятся при загрузке, четыре зоны v1-v3 превращаются в пять сегментов.

| Смещение | Поле | По умолчанию |
|---|---|---|
| 0 | ver = 4 | |
| 1, 2 | яркость габарита, стопа и поворота | 40, 255 |
| 3 | флаги: 0x01 ток с обратным знаком, 0x02 белый спереди, 0x04 разметка, 0x08 габариты колеса со стопом | 0x02 |
| 4 | сглаживание ускорения u16, мс | 250 |
| 6, 8, 10, 12 | пороги: замедление, ток рекуперации, разгон (0.1 км/ч/с, 0.1 А), мин. скорость 0.1 км/ч | 50, 0, 40, 30 |
| 14 | точек всего u16 (сумма сегментов) | 135 |
| 16-22 | зоны v1-v3, только для переноса | |
| 24 | цвет разгона RGB | 0, 200, 160 |
| 27 | поворот гаснет через, с | 15 |
| 28 | предел тока ленты u16, мА | 2000 |
| 30, 32 | наклон назад сверх среднего u16 0.01 град; среднее за, с | 250, 8 |
| 33 | порядок цветов: 0 GRB, 1 RGB, 2 BRG, 3 GRBW, 4 RGBW | 0 |
| 34 | kind: 0 шлем, 1 колесо | 0 |
| 35 | сегментов, 1..8 | 5 |
| 36-67 | сегменты по 4 байта: `[точек u16][роль u8][флаги u8, 0x01 - поворот бежит обратно]` | интеграл 15/40/25/40/15 |
| 68 | цвет педалей RGB | 255, 90, 0 |
| 71 | предупреждение от PWM, % (0 - выкл) | 85 |
| 72 | обод: 0x01 мигать при предупреждении, 0x02 при стопе, 0x04 гасить на стоянке > 30 с | 0x01 |
| 73 | ESP-NOW: 0x01 шлем пересылает режим колесу, 0x02 колесо берёт режим у шлема | 0x01 |

Роли: 0 перед справа, 1 бок справа, 2 зад, 3 бок слева, 4 перед слева, 5 стоп-полоса (стоп растёт от центра),
6/7 козырёк справа/слева, 8/9 ходовой огонь справа/слева (колесо), 10/11 габарит справа/слева (колесо),
12/13 педаль справа/слева, 14 не светит. Сегменты идут по цепочке ленты от платы.

**state**, 12 байт: `[mode][turn][accel s16][speed s16][packets u16][bad u16][ma u16]`,
mode: 0 нет связи, 1 норма, 2 стоп, 3 разгон, 4 предупреждение (PWM или тревога), 5 стоянка (стоит > 5 с).

**cmd**: `[1, что]` проверка 5 с (0 стоп, 1 габарит, 2 стоп, 3 разгон, 4/5/6 поворот лево/право/аварийка,
7 предупреждение, 8 стоянка, 9 разметка), на ходу быстрее 3 км/ч не включается; `[2, сегмент]` мигать сегментом 10 с
(255 - выкл); `[3, turn]` поворот.

**frame**: пока подписан - 5 раз в секунду кадр ленты после ограничения тока, кусками
`[смещение u16][сколько u8][RGB по 3 байта]`, до 60 точек в куске.

## Логика

- Ускорение - производная модуля скорости, сглаживание экспонентой `smooth_ms`. Медианы нет.
- Стоп: замедление, наклон назад сверх среднего (от 5 км/ч) или ток рекуперации выше порога. Выход на 60%,
  стоп и разгон держатся не меньше 300 мс.
- Предупреждение: PWM не ниже `warn_pwm` или бит тревоги - всё, кроме белого спереди, мигает красным и жёлтым.
- Стоянка: скорость ниже 1 км/ч дольше 5 с - педали показывают заряд колеса.
- Поворот: волна по сегментам своей стороны спереди назад (500 мс заполнение, 300 мс пауза), козырёк и педали мигают.
- Нет пакетов дольше 1 с, BLE отключён или flags бит 0 = 0 - «нет связи».
- Предел тока: 20 мА на канал на полной яркости + 1 мА на точку, выше предела всё притушивается.

## ESP-NOW

Канал 1. Кнопки поворотника: `'C' 'J' 1 cmd` (0 выкл, 1 лево, 2 право, 3 аварийка), повтор гасит.
Шлем пересылает колесу 5 раз в секунду и при смене режима: `'C' 'J' 2 mode turn` + data v2 (16 байт, широковещательно).
Колесо с `relay & 0x02` берёт режим и поворот у шлема, если телефон не пишет ему сам дольше 1 с.

## Отладка по USB

115200, команды: `l` `r` `b` `o` - поворот лево, право, оба, выкл; `c` - режим разметки вкл/выкл;
`d` - настройки по умолчанию; `s` - состояние.

## Приложение (этап 2)

Форк WheelLog с модулем «Шлем»: git на NL `/root/helmet-app`, ветка `shlem`
(исходник https://github.com/Wheellog/Wheellog.Android, f44e39e). Пакет `com.cooper.wheellog.helmet`,
имя «WheelLog Шлем», ставится рядом с WheelLog из Play.

- `app/.../helmet/Lighting.kt` - устройства (шлемы, колесо), связи, режим, проверка; `EspLink.kt` - плата CJ;
  `ZenggeLink.kt` - контроллер ZENGGE (протокол lednetwf_ble); `Detector.kt` - режим на телефоне без платы; `Cfg.kt` - config v4.
- `app/.../settings/LightingScreen.kt` - раздел «Подсветка»: список, устройство, сегменты, ZENGGE, проверка; от 600 dp - две колонки.
- `VeteranAdapter.java` - скорость и фазный ток со знаком до настройки «отрицательные значения» (`WheelData.setHelmetRaw`).
- Синхронизации с electro.club нет: ключ `ec_accessToken` есть только в официальной сборке.

Сборка на MiniGUN: перенести `git archive shlem | tar x` в `/opt/helmet/wheellog`, затем `/opt/helmet/sobrat-apk.sh`
(release, подпись `/opt/helmet/android/helmet.jks`, пароль `apk=` в `/opt/helmet/sekrety.txt`).
Раздача: http://10.10.0.16/dl/wheellog-shlem.apk. Эмулятор для проверки экрана: AVD `tel`, `tools/emu_tap.py`.
