# CJ: шлемы и колесо со светом - шаги проекта

Форк WheelLog: приложение подключается к колесу Sherman L, считает разгон, торможение и
повороты и управляет светом на шлемах и на самом колесе. Прошивка плат - в этой же папке
(`fw/`, `tools/`), приложение - в обычном дереве WheelLog (модуль `helmet/`, экран
`settings/LightingScreen.kt`).

Порядок ниже - как шла работа. Коммиты по шагам видны в истории ветки `shlem`,
метки `cj-*` отмечают конец каждого шага.

## Шаг 1. Шлем со стоп-сигналом (23-24.10.2026) - метка `cj-1-shlem`

Прошивка (ESP32-C6 в шлеме HJC RPHA 70):
- этап 1: протокол, проверка по BLE, лог по USB, показ режимов на живом шлеме;
- чтение Sherman L по BLE только на чтение;
- пороги по логам езды: стоп по наклону, без медианы;
- обновление по Wi-Fi (ArduinoOTA), тип ленты в настройках.

Приложение:
- модуль «Шлем»: BLE к шлему, экран настроек под складной телефон, своё applicationId
  (ставится рядом с WheelLog из Play);
- ползунки порогов, кнопка шлема в верхней строке.

## Шаг 2. Свет колеса и роли плат (24.10.2026) - метка `cj-2-svet-koleso`

- прошивка v4: сегменты ленты вместо зон, роли «шлем» и «колесо», ESP-NOW шлем - колесо;
- приложение: раздел «Подсветка» - шлемы и колесо в одном списке, платы CJ (config v4,
  сегменты, проверка), подтверждение удаления устройства.

## Шаг 3. Дополнительный контроллер ZENGGE (24.10.2026) - метка `cj-3-zengge`

- второй шлем LS2 со штатным Bluetooth-контроллером ZENGGE (LEDnetWF): телефон держит
  связь со всеми устройствами, где стоит галка оборудования, а не только с «активным»;
- для шлема без платы пороги считает телефон;
- переименование устройства без потери связей. Версия приложения shlem4.

## Шаг 4. Провод: плата читает колесо напрямую (24.10.2026) - метка `cj-4-provod`

- режим «провод»: плата слушает RXD Bluetooth-модуля колеса (ZS-040, 115200);
- мост USB-UART для чтения модуля колеса (C6 и ESP32);
- распиновка штатного разъёма колеса и точки подключения (фото `docs-*.jpg`);
- PWM и заряд по напряжению из пакета колеса.

## Сборка

- APK: GitHub Actions, workflow `CJ Helmet APK` - на каждую заливку в `shlem`; на метку
  `cj-*` APK уходит в Releases. Подпись - секреты HELMET_KS_B64 и HELMET_KS_PASS.
- Прошивка: на MiniGUN `/opt/helmet/sobrat.sh -e nano-c6` (или `c3-mini`); пароли Wi-Fi и
  OTA - в `sekrety.h`, который создаётся на MiniGUN и в git не кладётся.
