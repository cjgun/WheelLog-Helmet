## Картинки ChatGPT (gpt/)

1. Два стиля, Industrial и Night Ride.
2. Industrial, экраны по ТЗ: стиль удачный, содержимое местами выдумано.
3. Industrial, экраны колеса: GPT «ушёл в дебри», содержимое выдумано.

## Пометки владельца (pometki/)

Скриншоты с красными пометками, по порядку:
1. Одометр всегда под скоростью.
2. В «Цифре» одометр лишний; свет показывать просто «вкл/выкл».
3. Сделать красивее значки; часы, возможно, не нужны.
4. Кнопку записи убрать (автозапись), вместо неё Bluetooth; шапка кривая; имя колеса перенести.
5. В «Приборе» не показывать ячейки, убрать имя.
6. В «Цифре» убрать строку мин/макс; вместо трёх полосок шестерёнка.
